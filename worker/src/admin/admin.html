Cloudflare Turnstile

在发短信之前拦截机器人，避免有人刷你的短信费。免费且不限量。 到 Cloudflare 控制台 Turnstile → Add widget 创建，两个 Key 都填在这里。

在 Turnstile 的 Hostnames 里填上你所有落地页的域名， 否则别的网站可以盗用你的验证额度。

允许的国家

只勾一个国家 = 只允许该国号码。注意美国和加拿大都是 +1，系统按号码段区分。

频率限制

防止单个号码或 IP 被反复刷短信。设为 0 表示不限制。

免验时长设 0 表示每次点击都要重新验证；设 24 表示通过后 24 小时内免验证。

跳转目标

client：链接留在落地页里，验证通过后由页面跳转（最简单，推荐）。 server：验证通过后由服务端下发链接，源码里看不到真实链接（更安全）。

允许调用的站点

只有列表里的域名可以调用验证接口。这是防止别人盗用你短信额度的重要一道闸， 上线后建议把 * 换成你自己的落地页域名。

每行一个，带 https:// 前缀；填 * 表示不限制。
